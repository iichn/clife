# C-Life: Vision

## Проблема
Слишком много приложений для рутины + нет ни одного, которое дало бы максимально возможный выбор различных типов задач/счётчиков (давность, "раз в N дней", метро в месяц) + нужен быстрый офлайн-инструмент.

## Видение
Для меня (и друзей по ссылке) C-Life - модульное Android-приложение,
которое собирает жизненные трекеры в одном месте. Первый модуль - Life:
счётчики и задачи на одном экране. Остальное добавляется как новые модули/расширение уже имеющихся.

## Цели
1. Ежедневное личное использование.
2. Архитектура, к которой модули добавляются без переписывания.
3. Аккуратный репозиторий и документация (учебная цель).
Портфолио - побочный эффект, не цель.

## Критерии успеха РЕЛИЗА 1 (v1000)
- S1: счётчики и задачи работают офлайн, 0 вылетов за 14 дней личного использования.
- S2: +1 к счётчику не более чем за 2 касания с главного экрана.
- S3: схема БД из bd.md реализована полностью.
- S4 (v1000): UI на стандартных компонентах Material 3 с dynamic color (Monet), без кастомной типографики и анимаций.
- S5 (v1100): экран выглядит завершённо по гайдам Material 3 Expressive.

## Принципы
Офлайн-first, без аккаунтов, данные только на устройстве, GPLv3, без гарантий поддержки.

## Риски и допущения
- Время: минимум 3 ч/неделю.
- Мотивация волнообразная: держать релизы короткими.
- Код пишет ИИ: качество держится на ТЗ и приёмке.
