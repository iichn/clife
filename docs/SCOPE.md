# C-Life: Scope

## Версионирование
Целое число. РЕЛИЗ = +1000, большой патч = +100 (0-9), патч = +1 (0-99).
1000 = РЕЛИЗ 1 (функционал), 1100 = UI-веха РЕЛИЗА 1, 2000 = РЕЛИЗ 2.
В Android `versionCode` = это число, `versionName` = release1mark1patch3 (для 1103).
