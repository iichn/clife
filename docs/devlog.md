* задача (повторяющаяся(по календарю, от прошлого выполнения) и нет)
* счетчик (кнопки "+1", "-1", и сброс)
Выполненные задачи помечаются (цвет, зачеркнутый текст) и перемещаются(?). схема бд:

задача (task):
айди
название
описание -- может быть null
создана_в
изменена_в
выполнена_в -- может быть null (если это очередное выполнение писать значение в последнее_выполнение)
удалена_в -- может быть null
тип_повтора -- выбор: null\по_календарю\от_выполнения
повтор_интервал -- число > 0 (каждые N ...)
повтор_единица -- выбор: null\день\неделя\месяц
повтор_до -- может быть null
последнее_выполнение -- может быть null
следующая_дата -- может быть null

событие_задачи (task_event):
айди
задача_айди
тип -- выбор: выполнение\завершение_серии
создано_в

*Если тип_повтора = null, то повтор_интервал и повтор_единица тоже null.*
*Когда выполняется повторяющаяся задача: ставим сегодня в последнее_выполнение и пересчитываем следующая_дата (от_выполнения: сегодня + интервал; по_календарю: прошлая следующая_дата + интервал).Если новая следующая_дата позже повтор_до — выполнена_в = сейчас, следующая_дата = null (серия закрыта)*
*например: когда выполняется задача с повторением от_выполнения,мы ставим нынешнюю дату в последнее_выполнение, выполнена_в не трогаем, а следующая_дата=сегодня + интервал! (если нет условия для завершения цикла).*

вопрос из зала: Что будет с задачей «по_календарю, каждую неделю», если ты отметишь её выполненной через три недели после следующая_дата? Задача догонит пропущенные недели или перескочит сразу в будущее?
ответ: по умолчанию задача продолжит повторяться, даже если она не выполнена, так что после выполнения после пропусков выполнится самая последняя копия задачи (потом добавим одельный экран для каждой задачи\счетчика где помимо прочего можно будет выполнять прошлые копии задачи)

счётчик (counter):
айди
название
описание
создан_в
изменён_в
цель_значение -- может быть null
цель_период -- выбор: null\день\неделя\месяц
удалён_в -- может быть null

*Если цель_значение = null, то цель_период тоже null. Null в цель_период при заданной цели я трактую как «за всё время».*

событие_счётчика (counter_event):
айди

это_сброс -- значение считается после последнего сброса
создано_в
